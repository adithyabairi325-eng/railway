# RailMaint AI - Railway Maintenance Optimization System

## How to Open the Application

### Option 1: Open the Built Version (Recommended)
1. Navigate to: `C:\Users\Bairy Adhithya\railway-maintenance-system\dist`
2. Double-click on `index.html` 
3. The application will open in your default browser

### Option 2: Run Development Server
1. Open Command Prompt or PowerShell
2. Navigate to the project folder:
   ```
   cd "C:\Users\Bairy Adhithya\railway-maintenance-system"
   ```
3. Run the development server:
   ```
   npm run dev
   ```
4. Open your browser and go to: `http://localhost:3000`

## Features
✅ Dashboard with real-time metrics and analytics
✅ Maintenance Request Management
✅ AI-Powered Schedule Optimizer
✅ What-If Simulator for scenario testing
✅ Asset Management with predictive analytics
✅ Comprehensive Reports & Analytics
✅ Notifications Center
✅ User Settings & Preferences

## System Workflow
1. **Login** → Role-based authentication
2. **Dashboard** → Overview of maintenance operations
3. **Create Request** → Submit new maintenance requests
4. **Schedule Optimizer** → AI generates optimal maintenance schedules
5. **What-If Simulator** → Test different scenarios
6. **Asset Management** → Track asset health and history
7. **Analytics** → View performance metrics and insights
